01.

About

Computer vision engineer and rancher from Antlers, Oklahoma. I built a production cattle weight estimation system — phone-based CV and drone LiDAR — validated against real chute data and verified scale weights from my family's operation.

I work across the full stack: model architecture, data pipelines, mobile deployment, and custom drone hardware. 20+ years running cattle; my daughters manage the day-to-day ranch now while I focus on technology.

Right now I'm building toward a verified identity + value layer for cattle — a long-range ear tag plus unremovable bolus, cryptographically bound to each animal and drone-readable, so a banker can lend against the cow, an insurer can cover it, and a buyer can trust the verified-attribute premium. Adjacent to (not competitive with) virtual fencing stacks: I focus on what each animal is and what it's worth, while location-tracking companies handle where it is.

Generational Ranching — daughters run daily ops; I run tech
